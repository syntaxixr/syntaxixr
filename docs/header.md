# Header

Banner from [capsule-render](https://github.com/kyechan99/capsule-render).

- `type=waving`, `height=240`, `animation=twinkling`
- gradient `0:000000,45:3b0764,75:7f00ff,100:bf00ff`
- `text` / `desc` set the title and subtitle; spaces are `%20`, `·` is `%C2%B7`

Thin section dividers use the same service with `type=rect&height=2`.
